# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could lead to command
injection, privilege escalation, secret disclosure, unsafe rollback, or remote
lockout. Contact the repository maintainer privately. 

## Trust model

Linux Hardening Agent deliberately separates language-model advice from command
generation:

- The model reviews source metadata but cannot create executable controls.
- The complete rule set comes from the selected installed OpenSCAP profile.
- Selected rule IDs are revalidated against the latest failed scan results.
- Remediation is generated by OpenSCAP from a fresh selected-rule result and requires review.
- SSH uses the system OpenSSH client with host-key checking enabled.
- Passwords and private keys are never sent to Ollama.

## Local GUI

The GUI is an operator convenience layer, not a privileged execution service.
It binds to loopback by default, uses a random per-process request token for API
mutations and downloads, validates local `Host` headers, limits JSON request
sizes, and sends restrictive browser security headers. It refuses to run as root
unless the explicit `--allow-root` troubleshooting option is supplied.

Use libvirt group membership for KVM discovery. Do not start a graphical browser
or the long-running web server through `su`. Do not use `--allow-remote` on an
untrusted network; the GUI has no user-account authentication or TLS termination.
Generated scripts remain inert until the operator separately runs them with the
documented `--apply` or `--rollback` flag.

The initial release is not a compliance certification product. Review generated
bundles and test them on disposable systems before production use.
