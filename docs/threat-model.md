# Threat model

## Protected assets

- target-system availability and administrative access
- SSH keys and credentials
- system configuration and audit evidence
- integrity of generated remediation bundles
- authoritative manufacturer policy and source mapping

## Principal threats

- prompt injection embedded in hostnames, banners, logs, or configuration
- language-model hallucination
- command injection through parameters
- tampered SCAP content, reports or generated bundles
- malicious SSH host substitution
- remote administrator lockout
- incomplete rollback
- secrets entering prompts or logs
- browser requests reaching a privileged or remotely exposed GUI

## Mitigations

- inventory is treated as untrusted data
- model output is restricted to source review and candidate ranking
- selected remediation IDs are revalidated against the latest failed scan results
- remediation shell is generated by the installed OpenSCAP policy from a fresh result
- SSH host keys are checked
- root execution is separate and explicit
- file backups and verification scripts are generated
- bundle checksums detect accidental post-generation modification
- the GUI defaults to loopback, refuses root, validates local host headers,
  requires a per-process token for mutations/downloads, limits request sizes,
  and has no endpoint that applies hardening

## Residual risks

- vendor SCAP content or generated remediation may still contain an implementation defect
- distribution updates can change configuration behavior
- package installation cannot be fully undone by file restoration
- KVM snapshots can be inconsistent for active applications
- a local attacker controlling the repository or Python environment can alter
  generated output
- SHA-256 checksums are integrity aids, not signatures
- the GUI has no account authentication or TLS and is not intended for direct
  network exposure

Production deployments should sign releases, verify SCAP packages, run from a
dedicated administrative host, and use independent configuration/compliance
verification.
